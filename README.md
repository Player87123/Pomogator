# VK-бот для опросов в беседе

Бот создаёт неанонимные опросы в чате ВКонтакте, собирает статистику
и через заданное время напоминает тем, кто не ответил.

## 1. Настройка сообщества

1. Создайте сообщество ВК (если ещё нет) — Управление → Работа с API → Ключи доступа →
   создать ключ с правами **"Сообщения сообщества"**.
2. Скопируйте токен — он понадобится в `.env`.
3. **Добавьте сообщество как бота в нужную беседу**:
   в беседе → Управление беседой → Участники → Добавить → выбрать сообщество.
4. **Сделайте бота администратором беседы** — это обязательно, иначе он не
   сможет получить список участников (`messages.getConversationMembers`)
   и упоминать тех, кто не ответил.
5. В настройках сообщества включите **Long Poll API** (Настройки → Работа с API →
   Long Poll API → Включить), тип событий — "Обычные события".

## 2. Установка

```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Откройте `.env` и вставьте токен сообщества (`GROUP_TOKEN`), при желании
поменяйте `REMINDER_HOURS` (через сколько часов слать напоминание).

## 3. Запуск

```bash
python bot.py
```

Бот должен работать постоянно (например, на VDS через `systemd`/`screen`/`tmux`,
или через Docker), чтобы вовремя присылать напоминания — это не облачная функция
по расписанию, а постоянно работающий процесс.

## 4. Команды в беседе

- `/poll Вопрос?|Вариант1|Вариант2|Вариант3` — создать опрос
  (вариант с переносами строк тоже работает: `/poll` на первой строке,
  вопрос и варианты — на следующих).
- `/polls` — список активных опросов и их номера.
- `/stats <номер>` — текущая статистика: сколько ответили и кто ещё нет.
- `/help` — подсказка по командам.

Напоминание с упоминанием тех, кто не проголосовал, отправляется автоматически
через `REMINDER_HOURS` часов после создания опроса.

## 5. Список детей и родителей

Управлять списком (добавлять/удалять) могут **только администраторы беседы**
(проверяется через `messages.getConversationMembers`, поле `is_admin`/`is_owner`).
Смотреть список может любой участник.

- `/add_child Имя Фамилия | @родитель1 @родитель2` — добавить ребёнка сразу с
  родителями. Родителей нужно выбрать из подсказок ВК при вводе `@`, чтобы
  они превратились в кликабельное упоминание `[id...|Имя]` — именно по этому
  упоминанию бот распознаёт пользователя.
- `/add_child Имя Фамилия` — добавить ребёнка без родителей, прикрепить их позже.
- `/add_parent <номер_ребёнка> @родитель` — прикрепить ещё одного родителя
  (у ребёнка может быть несколько).
- `/remove_parent <номер_ребёнка> @родитель` — открепить родителя.
- `/remove_child <номер_ребёнка>` — удалить ребёнка из списка.
- `/children` — полный список детей с указанием родителей и их номерами.
- `/my_children` — список детей, закреплённых за пишущим (доступно всем).

Пример:
```
/add_child Иванова Соня | @Мама Ивановой @Папа Иванов
```

## 6. Учёт оплат за турнир

Сумма за турнир — **одна для всех** и списывается по каждому ребёнку из
существующего списка (`/add_child`). Отмечает оплату **сам родитель**
(проверяется, что пишущий — один из родителей ребёнка), администраторы тоже
могут отмечать за любого.

- `/tournament Название | Сумма` — создать турнир (только админы). В участники
  автоматически попадают **все дети из текущего списка** на момент создания.
- `/tournaments` — список активных турниров и суммы.
- `/tournament_add_child <номер_турнира> <номер_ребёнка>` — добавить ребёнка,
  если его вписали в список уже после создания турнира (админы).
- `/paid <номер_ребёнка> [номер_турнира]` — родитель отмечает оплату за своего
  ребёнка. Номер турнира можно не указывать — возьмётся последний открытый.
- `/unpaid <номер_ребёнка> [номер_турнира]` — снять отметку, если родитель
  ошибся или оплата не прошла (админы).
- `/debts [номер_турнира]` — сколько уже собрано и кто ещё должен, с
  упоминанием родителей. Без номера — берётся последний открытый турнир.
- `/tournament_close <номер_турнира>` — закрыть турнир, когда сборы завершены
  (админы; закрытый турнир пропадает из `/tournaments` и `/debts` по умолчанию).

Пример:
```
/tournament Городской турнир | 1500
/debts
```

## 7. Список детей и родителей — зашит в код (seed_data.py)

Данные из твоего файла `родители_для_бота_вк.xlsx` уже перенесены в
`seed_data.py` — отдельный модуль со списком `CHILDREN`, никакой xlsx-файл
на сервере больше не нужен.

**Формат записи в `seed_data.py`:**
```python
CHILDREN = [
    ("Гребнев Матвей Иванович", [
        ("Гребнев Иван Витальевич", None),                 # VK-профиль неизвестен
        ("Гребнева Марина Павловна", "marinamorskaya2020"), # screen_name — резолвится в id
    ]),
    ("Ильичев Макар Алексеевич", [
        ("Ильичев Алексей Юрьевич", 833281213),             # уже готовый числовой id
        ("Ильичева Вера Васильевна", 2256458),
    ]),
    ...
]
```
Чтобы добавить/поправить ребёнка — правь этот список напрямую в коде.

**Как запустить импорт в базу:**
1. Узнайте `peer_id` беседы — отправьте в чат `/chatid`, бот ответит числом.
2. Из папки бота (там же, где `.env` и `polls.db`) запустите:
   ```bash
   python seed_import.py <peer_id>
   ```
3. Скрипт создаст всех детей, резолвнёт screen_name в VK id через
   `utils.resolveScreenName`, и выведет:
   - сколько родителей привязано к каждому ребёнку;
   - кого не удалось резолвнуть (профиль удалён/переименован) — добавить
     вручную: `/add_parent <номер_ребёнка> @актуальный_ник`;
   - у кого VK-профиль вообще неизвестен (`None` в `seed_data.py`) — то же самое.

⚠️ Повторный запуск `seed_import.py` создаст детей **заново** (дубликатами) —
если нужно перезалить данные с нуля, сначала удалите старые записи через
`/remove_child`, либо просто остановите бота и удалите файл `polls.db`.

**Альтернатива — автозагрузка при первом старте бота.** Если в `.env` указать
`SEED_PEER_ID=<peer_id беседы>`, бот сам, один раз при первом запуске (когда
для этой беседы ещё нет ни одного ребёнка в базе), загрузит данные из
`seed_data.py` — отдельно запускать `seed_import.py` не нужно. При повторных
перезапусках бота повторной загрузки не будет (проверяется по наличию уже
добавленных детей), поэтому дублирования не произойдёт.

## Важные ограничения

- **Опросы всегда неанонимные** (`is_anonymous=False`) — иначе VK API не отдаёт,
  кто именно проголосовал, и посчитать "не ответивших" невозможно. Участников
  беседы стоит об этом предупредить.
- Список участников фиксируется **в момент создания опроса** — если после этого
  кто-то вступит или выйдет из беседы, список "не ответивших" не обновится
  автоматически (можно доработать при необходимости).
- Данные хранятся в файле `polls.db` (SQLite) рядом со скриптом — при переносе
  бота на другой сервер скопируйте и этот файл, если нужна история.
